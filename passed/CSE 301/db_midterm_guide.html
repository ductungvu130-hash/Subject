🏛️1. Entity, Attribute & Khóa (Key)

Entity là đối tượng thực tế hệ thống cần lưu. Trong MySQL mỗi entity → 1 TABLE.

  • Primary Key (PK): Định danh duy nhất mỗi dòng. Khai báo bằng PRIMARY KEY. Tự động NOT NULL + UNIQUE.
  • Composite PK: PK gồm nhiều cột → khai báo ở cuối: PRIMARY KEY (col1, col2)
  • Foreign Key (FK): Cột tham chiếu PK bảng khác → FOREIGN KEY (col) REFERENCES Table(pk)
  • Weak Entity: Entity không có PK riêng, phụ thuộc entity khác (VD: invoice_detail phụ thuộc invoice).

🔒3. Constraints trong MySQL

  • NOT NULL — Cột bắt buộc phải có giá trị, không được để trống.
  • UNIQUE — Tất cả giá trị trong cột phải khác nhau (cho phép NULL). VD: email, phone.
  • DEFAULT 'val' — Tự điền giá trị mặc định khi INSERT không chỉ định cột đó.
  • CHECK (expr) — Giá trị phải thỏa điều kiện logic. MySQL hỗ trợ và enforce từ v8.0.16+.
  • AUTO_INCREMENT — Tự tăng số nguyên mỗi lần INSERT. Thường dùng với INT PRIMARY KEY.
MySQL — Ví dụ tất cả constraints
CREATE TABLE Example (
    id        INT            AUTO_INCREMENT PRIMARY KEY,
    email     VARCHAR(150)  NOT NULL UNIQUE,
    status    VARCHAR(20)   DEFAULT 'Active',
    score     INT            CHECK (score >= 0 AND score <= 100),
    type      ENUM('A','B')  NOT NULL,
    CONSTRAINT chk_named CHECK (score > 0)  -- constraint có tên
);

🏗️4. Lệnh CREATE TABLE đầy đủ

MySQL — CREATE DATABASE + USE + CREATE TABLE
-- Bước 1: Tạo database
CREATE DATABASE IF NOT EXISTS ten_database;
USE ten_database;

-- Bước 2: Tạo bảng (theo thứ tự: bảng được REFERENCES trước)
CREATE TABLE ParentTable (
    parent_id   INT           PRIMARY KEY,
    name        VARCHAR(100) NOT NULL
);

CREATE TABLE ChildTable (
    child_id    INT           PRIMARY KEY,
    parent_id   INT           NOT NULL,
    email       VARCHAR(150) UNIQUE,
    status      VARCHAR(20)  DEFAULT 'Active',
    score       INT,
    CONSTRAINT fk_child_parent FOREIGN KEY (parent_id) REFERENCES ParentTable(parent_id),
    CONSTRAINT chk_score       CHECK (score >= 0)
);

-- Composite Primary Key (2+ cột) — bảng trung gian M:N
CREATE TABLE BridgeTable (
    id1  INT  NOT NULL,
    id2  INT  NOT NULL,
    PRIMARY KEY (id1, id2),
    CONSTRAINT fk_bridge_a FOREIGN KEY (id1) REFERENCES TableA(pk),
    CONSTRAINT fk_bridge_b FOREIGN KEY (id2) REFERENCES TableB(pk)
);

-- Kiểm tra kết quả
SHOW TABLES;
DESCRIBE ChildTable;
⚠️Thứ tự tạo bảng! Bảng được REFERENCES phải tạo TRƯỚC. VD: Section → Book; Member & Librarian → Borrowing. Nếu tạo sai thứ tự sẽ bị lỗi "Cannot add foreign key constraint".

✏️5. Lệnh ALTER TABLE — Tất cả cú pháp MySQL

MySQL — ALTER TABLE — Tất cả patterns
-- 1. Thêm cột mới
ALTER TABLE TenBang
ADD COLUMN ten_cot VARCHAR(100) NOT NULL;

-- 2. Sửa định nghĩa cột (MySQL dùng MODIFY, không phải ALTER COLUMN TYPE)
ALTER TABLE TenBang
MODIFY COLUMN ten_cot VARCHAR(200) NOT NULL DEFAULT 'value';

-- 3. Thêm DEFAULT (cách nhanh, không cần ghi lại toàn bộ kiểu)
ALTER TABLE TenBang
ALTER COLUMN ten_cot SET DEFAULT 'GiaTri';

-- 4. Xóa DEFAULT
ALTER TABLE TenBang
ALTER COLUMN ten_cot DROP DEFAULT;

-- 5. Thêm CHECK constraint (MySQL 8.0.16+)
ALTER TABLE TenBang
ADD CONSTRAINT chk_ten_constraint
CHECK (dieu_kien_logic);

-- 6. Thêm UNIQUE
ALTER TABLE TenBang
ADD CONSTRAINT uq_ten UNIQUE(ten_cot);

-- 7. Thêm PRIMARY KEY (bảng chưa có PK)
ALTER TABLE TenBang
ADD PRIMARY KEY (ten_cot);

-- 8. Thêm FOREIGN KEY
ALTER TABLE TenBang
ADD CONSTRAINT fk_ten
FOREIGN KEY (cot_fk) REFERENCES BangKhac(pk);

-- 9. Xóa constraint theo tên
ALTER TABLE TenBang
DROP CONSTRAINT ten_constraint;

-- 10. Xóa cột
ALTER TABLE TenBang
DROP COLUMN ten_cot;

-- 11. Đổi tên cột
ALTER TABLE TenBang
RENAME COLUMN ten_cu TO ten_moi;
💡MySQL vs PostgreSQL: MySQL dùng MODIFY COLUMN để thay đổi kiểu dữ liệu (PostgreSQL dùng ALTER COLUMN col TYPE). Để chỉ thêm DEFAULT trong MySQL có thể dùng ALTER COLUMN col SET DEFAULT hoặc MODIFY COLUMN col TYPE DEFAULT val.

❓7. NULL trong MySQL — Bẫy thường gặp

  • NULL = "không có giá trị" — khác hoàn toàn với 0 hay chuỗi rỗng ''
  • Mọi phép so sánh với NULL (= NULL, > NULL) đều trả về UNKNOWN, không phải TRUE/FALSE.
  • Phải dùng IS NULL hoặc IS NOT NULL để kiểm tra NULL.
  • Trong CHECK: nếu cột có thể NULL → phải xử lý: col IS NULL OR col > something
  • MySQL: khi CHECK expression cho kết quả NULL, MySQL vẫn ALLOW INSERT (NULL treated as passing).
NULL — Sai và đúng
-- SAI: Luôn cho kết quả UNKNOWN khi ReturnDate = NULL
CHECK (ReturnDate > BorrowDate)  -- block record chưa trả!

-- ĐÚNG: Cho phép NULL (chưa trả) hoặc ReturnDate hợp lệ
CHECK (ReturnDate IS NULL OR ReturnDate > BorrowDate)

➕8. INSERT INTO — Chèn dữ liệu

Lệnh INSERT INTO dùng để thêm một hoặc nhiều hàng dữ liệu vào bảng. Phải tuân thủ tất cả constraint đã định nghĩa (NOT NULL, UNIQUE, FK, CHECK...).

① Cú pháp cơ bản
MySQL — INSERT cú pháp
-- Cách 1: Khai báo cột (KHUYÊN DÙNG — rõ ràng, an toàn)
INSERT INTO TênBảng (cột1, cột2, cột3)
VALUES ('giá_trị_1', 'giá_trị_2', 100);

-- Cách 2: Không khai báo cột (phải điền ĐỦ tất cả cột theo thứ tự)
INSERT INTO TênBảng
VALUES (1, 'giá_trị_1', 'giá_trị_2', 100);

-- Cách 3: INSERT nhiều hàng cùng lúc (hiệu quả hơn nhiều lần INSERT đơn)
INSERT INTO TênBảng (cột1, cột2)
VALUES
    ('hàng_1_c1', 'hàng_1_c2'),
    ('hàng_2_c1', 'hàng_2_c2'),
    ('hàng_3_c1', 'hàng_3_c2');
② Giá trị đặc biệt khi INSERT
MySQL — Giá trị đặc biệt
-- NULL: dùng cho cột nullable (ReturnDate, Phone...)
INSERT INTO Borrowing (BorrowID, BorrowDate, DueDate, ReturnDate, BookID, MemberID)
VALUES (1, '2024-01-10', '2024-01-24', NULL, 2, 1);
--                                           ↑ chưa trả → ReturnDate = NULL

-- DEFAULT: bỏ qua cột có DEFAULT, MySQL tự điền
INSERT INTO Book (BookID, Title, Author)
VALUES (5, 'Clean Code', 'Robert C. Martin');
-- → Status tự nhận DEFAULT 'Available' (không cần khai báo)

-- Hoặc ghi rõ DEFAULT keyword
INSERT INTO Book (BookID, Title, Author, Status)
VALUES (6, 'Python', 'Mark Lutz', DEFAULT);
-- → DEFAULT keyword → tự điền 'Available'

-- CURRENT_DATE / NOW(): điền ngày giờ hiện tại
INSERT INTO Borrowing (BorrowID, BorrowDate, DueDate, BookID, MemberID)
VALUES (10, CURRENT_DATE, DATE_ADD(CURRENT_DATE, INTERVAL 14 DAY), 1, 2);
-- → BorrowDate = hôm nay, DueDate = hôm nay + 14 ngày

⑤ INSERT kết hợp SELECT (nâng cao)

-- Copy dữ liệu từ bảng khác vào bảng hiện tại

VALUES (1, 'Clean Code', 'Checked Out')

MySQL — library_management.sql
CREATE DATABASE IF NOT EXISTS library_management;
USE library_management;

-- ─────────────────────────────────────────
-- Table 1: SECTION
-- ─────────────────────────────────────────
CREATE TABLE Section (
    SectionID    INT           PRIMARY KEY,
    SectionName  VARCHAR(100) NOT NULL,
    Location     VARCHAR(150)
);

-- ─────────────────────────────────────────
-- Table 2: BOOK
-- ─────────────────────────────────────────
CREATE TABLE Book (
    BookID           INT           PRIMARY KEY,
    Title            VARCHAR(255) NOT NULL,
    Author           VARCHAR(150) NOT NULL,
    PublicationYear  INT,
    Category         VARCHAR(80),
    Status           VARCHAR(20)  DEFAULT 'Available',
    SectionID        INT,
    CONSTRAINT fk_book_section
        FOREIGN KEY (SectionID) REFERENCES Section(SectionID)
);

-- ─────────────────────────────────────────
-- Table 3: MEMBER
-- ─────────────────────────────────────────
CREATE TABLE Member (
    MemberID    INT           PRIMARY KEY,
    Name        VARCHAR(100) NOT NULL,
    MemberType  VARCHAR(10)  NOT NULL,
    Email       VARCHAR(150) UNIQUE,
    Phone       VARCHAR(20)
);

-- ─────────────────────────────────────────
-- Table 4: LIBRARIAN
-- ─────────────────────────────────────────
CREATE TABLE Librarian (
    LibrarianID  INT           PRIMARY KEY,
    Name         VARCHAR(100) NOT NULL,
    Email        VARCHAR(150) UNIQUE,
    Phone        VARCHAR(20)
);

-- ─────────────────────────────────────────
-- Table 5: BORROWING
-- (tạo sau cùng, tham chiếu 3 bảng trên)
-- ─────────────────────────────────────────
CREATE TABLE Borrowing (
    BorrowID      INT          PRIMARY KEY,
    BorrowDate    DATE         NOT NULL,
    DueDate       DATE         NOT NULL,
    ReturnDate    DATE         NULL,
    ReturnStatus  VARCHAR(30),
    BookID        INT          NOT NULL,
    MemberID      INT          NOT NULL,
    LibrarianID   INT,
    CONSTRAINT fk_borrow_book
        FOREIGN KEY (BookID)       REFERENCES Book(BookID),
    CONSTRAINT fk_borrow_member
        FOREIGN KEY (MemberID)    REFERENCES Member(MemberID),
    CONSTRAINT fk_borrow_librarian
        FOREIGN KEY (LibrarianID) REFERENCES Librarian(LibrarianID)
);

SHOW TABLES;

Q5a — Assign default 'Available' to Status column
✅ Default value cho Book.Status
💡Khi INSERT sách mới mà không điền Status, MySQL tự điền 'Available'. Dùng ALTER COLUMN ... SET DEFAULT hoặc MODIFY COLUMN.
MySQL — Q5a

ALTER TABLE Book
ALTER COLUMN Status SET DEFAULT 'Available';

-- Cách 2: MODIFY COLUMN (MySQL-specific)

Q5b — PublicationYear > 1990 and <= current year
✅ Check publication year range
💡YEAR(CURRENT_DATE) là hàm MySQL trả về năm hiện tại (VD: 2025). CHECK này đảm bảo sách không quá cũ (>1990) và không ở tương lai.
MySQL — Q5b
ALTER TABLE Book
ADD CONSTRAINT chk_publication_year
CHECK (
    PublicationYear > 1990
    AND PublicationYear <= YEAR(CURRENT_DATE)
);
Q5c — DueDate > BorrowDate; ReturnDate (if present) > BorrowDate
✅ Date logic constraints
💡Tại sao cần IS NULL OR? ReturnDate có thể NULL (sách chưa trả). So sánh NULL > BorrowDate cho kết quả UNKNOWN, không phải TRUE → phải xử lý NULL riêng.
MySQL — Q5c
ALTER TABLE Borrowing
ADD CONSTRAINT chk_borrowing_dates
CHECK (
    DueDate > BorrowDate
    AND (
        ReturnDate IS NULL
        OR ReturnDate > BorrowDate
    )
);
✅Đọc logic: "Hạn trả PHẢI sau ngày mượn" AND "Hoặc chưa trả (NULL), hoặc ngày trả thực tế cũng phải sau ngày mượn".
Q5d — MemberType only accepts 'Student' or 'Staff'
✅ Domain constraint for MemberType
💡Có 2 cách: dùng CHECK IN(...) hoặc đổi sang ENUM. Đề bài yêu cầu dùng CHECK nên dùng Cách 1.
MySQL — Q5d
-- Cách 1: CHECK với IN() — phù hợp với yêu cầu đề bài
ALTER TABLE Member
ADD CONSTRAINT chk_member_type
CHECK (MemberType IN ('Student', 'Staff'));

-- Cách 2: MODIFY sang ENUM (MySQL-specific)
ALTER TABLE Member
MODIFY COLUMN MemberType ENUM('Student', 'Staff') NOT NULL;
⚠️ENUM mạnh hơn nhưng khó mở rộng sau này. CHECK IN() linh hoạt hơn — nên dùng Cách 1 trong bài thi.
