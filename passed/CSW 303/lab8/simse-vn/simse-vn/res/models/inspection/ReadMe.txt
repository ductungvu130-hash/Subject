SimSE Inspection Model Read Me File

Model Author: Emily Navarro

Chào mừng đến với trò chơi mô phỏng SimSE Code Inspection! Bạn là quản lý dự án tại Scootie Software Company. Nhiệm vụ của bạn là điều phối nhân viên thực hiện inspection code, chọn số người tham gia, kích thước code và kích thước checklist, rồi quyết định thời điểm dừng inspection.

Mỗi lượt chơi chỉ có một inspection. Nếu bạn dừng inspection, bạn phải bắt đầu lại để thử một inspection khác.

Điểm tối đa là 100, dựa trên tỷ lệ số bug tìm thấy so với tổng số bug ban đầu trong code. Càng tìm được nhiều bug, điểm càng cao.
